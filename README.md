# 논증으로 완성하는 소논문형 보고서 — 단락 요지·동료 검토·수정 설계 디지털 교과서

단락 요지 쓰기를 중심으로, 논증 요소 분석 → 역개요 → AI 질문 검토 → 동료 피드백과 답변 → 수정개요 → 성찰까지 이어지는 10단계 학습 홈페이지입니다.

## 두 가지 상태

| 상태 | 조건 | 저장 위치 |
|---|---|---|
| 체험 모드 | `config.js`의 두 값이 비어 있음 | 각자의 브라우저 (예시 학생·교수자 계정으로 둘러보기) |
| 수업 모드 | `config.js`에 Supabase 주소·키 입력 | Supabase 서버 (로그인, 동료 공유, 교수자 확인) |

## 수업 모드 켜기 (휴대폰 브라우저로 가능)

1. **supabase.com** 가입 → **New project**. 지역은 *Northeast Asia (Seoul)*. 데이터베이스 비밀번호는 따로 적어 두기.
2. 왼쪽 메뉴 **SQL Editor** → **New query** → `setup.sql` 내용을 전부 붙여 넣기.
   맨 위 두 곳을 먼저 고친 뒤 **Run**:
   - `교수자코드를-바꾸세요` → 교수자만 아는 코드
   - `WRITING-A`, `WRITING-B` → 학생에게 알려 줄 분반 참여 코드
3. **Authentication → Sign In / Providers → Email**에서 **Confirm email**을 끄고 저장.
   (켜 두면 학생이 가입 확인 메일을 눌러야 로그인할 수 있습니다.)
4. 프로젝트 화면 위쪽 **Connect** 버튼을 누르면 **Project URL**과 **publishable 키**(`sb_publishable_…`)가 보입니다. 둘 다 복사. (Settings → API Keys에서도 볼 수 있습니다. 예전 anon 키도 동작하지만 2026년 말까지 폐지 예정이라 publishable 키를 권합니다.)
5. 두 값을 `config.js`에 넣기. (Claude에게 두 값을 알려 주면 대신 넣어 올려 줍니다. 두 값은 공개되어도 되는 값입니다. **secret 키(`sb_secret_…`)나 service_role 키는 절대 넣지 마세요.**)
6. 홈페이지에 접속해 **처음 가입**에서 이름·참여 코드 칸은 비워 두고, *교수자이신가요?*에 교수자 코드를 넣어 가입.
7. 학생에게 홈페이지 주소와 분반 참여 코드를 알려 주기.

## 접근 권한 (setup.sql에 들어 있음)

- 학생은 자기 글만 보고 고칠 수 있습니다.
- 학생이 7단계에서 **동료 검토용으로 공개**한 글만 같은 분반 학생이 읽고 메모·피드백·독자 요지를 남길 수 있습니다.
- 교수자는 모든 학생의 글과 기록을 보고 메모·피드백을 남길 수 있습니다.
- 분반 참여 코드와 교수자 코드는 학생 화면에서 조회할 수 없습니다.

## 운영 전 확인

- 학생 이메일과 글이 Supabase 서버(서울 지역)에 저장됩니다. 필요하면 기관의 개인정보 검토를 거치세요.
- Supabase 무료 프로젝트는 일주일 넘게 아무도 쓰지 않으면 일시 정지됩니다. 학기 중에는 문제가 없고, 방학 뒤에는 Supabase 화면에서 다시 켜면 됩니다.
- 5단계 AI 질문은 현재 학생의 분석을 규칙에 따라 점검하는 질문 생성기입니다. 실제 AI 연결은 서버 함수와 API 키가 필요해 다음 단계로 남겨 두었습니다.
